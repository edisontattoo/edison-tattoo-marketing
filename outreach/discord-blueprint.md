# Edison Ink Club — Discord Community Blueprint

A Discord server is the "unconventional channel" done right: it turns clients into a community that hangs out, shares healed tattoos, and hears about flash days first. This blueprint is complete — a human just needs to do the 2-minute server creation (Discord requires a real account to create a server; that's the one step I can't do).

## 1. Setup (2 minutes, human)

1. Open Discord → "+" → Create My Own → For me and my friends.
2. Name: **Edison Ink Club**. Upload a logo (shop logo.jpg works).
3. Server Settings → Roles → create roles per the table below.
4. Settings → Community → Enable Community (unlocks onboarding + rules).
5. Copy invite link → put it on the website contact page, in aftercare texts, on the counter sign. ("Join the Edison Ink Club — flash days, giveaway alerts, artist Q&As.")
6. Optional: add the MEE6 or Carl-bot via integrations for auto-role + welcome messages (free tier is enough).

## 2. Server structure

**Category: START HERE**
- `#welcome` — auto-post: "Welcome! Tell us your favorite piece you own (or the one you're planning). Read #rules, grab roles in #get-roles."
- `#rules` — see rules below
- `#get-roles` — self-assign: Tattooed, Tattoo-curious, Pierced, UNL Student, Flash-day alerts

**Category: THE SHOP**
- `#announcements` — staff only; flash drops, openings, sales, hiring news
- `#flash-days` — every flash sheet posted here first, 24h before it goes public
- `#aftercare-help` — clients post healing questions; staff answers (moderated)
- `#ask-an-artist` — weekly thread: submit design questions, artist answers Fridays

**Category: SHOW & TELL**
- `#healed-and-thriving` — healed tattoo pics (best engagement channel on Discord)
- `#fresh-ink` — day-of photos
- `#ink-ideas` — reference inspo + "would this work?" threads

**Category: OFF HOURS**
- `#lincoln-life` — general local chat (Huskers, food court rankings, shows)
- `#memes` — keep it shop-adjacent
- `#job-board` — hiring posts + apprentice Q&A (feeds the careers funnel!)

## 3. Roles

| Role | Color | Gets |
|---|---|---|
| Owner / Shop Manager | gold | everything |
| Artist / Piercer | cyan | staff channels |
| Ink Club Member | neon green | all public channels |
| Flash Day VIP | purple | early access ping (earned: 3+ months member or a piece of Edison work) |
| Tattoo-curious | grey | everything except staff |
| Muted / Timeout | grey | restricted (bot-managed) |

## 4. Rules (paste into #rules)

1. Be decent. We tattoo everyone — every body, every background. Zero tolerance for harassment.
2. No price-dumping wars, no "that's too expensive" pile-ons. Prices are the shop's to explain.
3. Healed-pics are welcome; fresh-needles close-ups are not. Keep it PG-13.
4. No soliciting, no promoting other shops' deals, no begging for free work.
5. Medical questions get pointed to the shop phone, not crowd-sourced.
6. Art theft = instant ban. Don't post another artist's work as a design request.
7. Mods' word is final. Appeal in DMs, not in channels.

## 5. Launch playbook (first 2 weeks)

- **Day 0:** staff join, fill channels, pin welcome. Test bot.
- **Day 1:** announce on Instagram/FB + QR code on the counter ("First 50 members get Flash Day VIP").
- **Day 3:** first `#ask-an-artist` thread (Friday).
- **Day 7:** first exclusive flash preview in `#flash-days` — post the sheet in Discord 24h before Instagram. This is the Discord's core promise: *members see it first.*
- **Day 10:** healed-ink contest — members vote, winner gets $25 off a walk-in.
- **Day 14:** announce the first Discord-only flash drop date.

## 6. Moderation

- Owner + one senior staff as mods; auto-mod bot handles spam/slurs.
- Staff answer #aftercare-help within a day or the bot bumps it.
- Weekly ritual: "Saturday check-in" post in #lincoln-life — what's everyone wearing to the game?

## 7. Metrics that matter

Members, weekly active, #healed-and-thriving posts/week, flash-day attendance from Discord vs IG. If Discord members book measurably more walk-ins (they will — they're the warmest audience you have), make Discord-only drops a permanent fixture.
